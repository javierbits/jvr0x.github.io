RepoBeagle

Static safety scanner for GitHub repos: a GREEN / YELLOW / RED verdict with file:line evidence before you clone or install. Never runs the code; catches prompt injection, MCP tool poisoning and install-time traps, entirely offline in a sandboxed container.
